# funktions_tmp_rerr.md — tmp / rerr / live

## 1. tmp (temporär)
tmp zeigt:
- wie lange jemand aktiv ist
- wie stabil jemand ist
- wie klar die Anfrage ist

Stufen:
- GRÜN → stabil
- GELB → unsicher
- ROT  → kritisch

## 2. rerr (Fehler/Abweichung)
rerr zeigt:
- ob etwas falsch ist
- ob etwas unklar ist
- ob etwas neu sortiert werden muss

Stufen:
- GRÜN → kein Fehler
- GELB → kleiner Fehler
- ROT  → Fehler aktiv

## 3. live-Neuaufbereitung
live zeigt:
- wie stark neu sortiert werden muss
- wie originell die Sicht sein soll

Stufen:
- GRÜN → normal
- GELB → leicht neu
- ROT  → komplett neu sortieren
