# SCHALTWERK :: VISUAL
Dieses Schaltwerk wandelt komplexe Sprache in einfache Sprache um.
Es nutzt QI/IQQ, TMP-Führung, arg.sync und NC.

───────────────────────────────────────────────
## 1. Input
Komplexe Sprache → RAW

───────────────────────────────────────────────
## 2. Schaltwerk
RAW → einfache Sprache
- Komma-Schaltung
- Feedback-Schaltung
- Transport-Schaltung

───────────────────────────────────────────────
## 3. QI/IQQ
QI = Themen-Schaltung (9)
IQQ = Unterthemen-Schaltung (81)

───────────────────────────────────────────────
## 4. TMP-Führung
help → error → miss → fit → fix → org → reorg

───────────────────────────────────────────────
## 5. arg.sync
Hin ↔ Zurück
SYNC = (Hin + Zurück) / 2

───────────────────────────────────────────────
## 6. Output
Einfache Sprache → transportierbar für jeden

───────────────────────────────────────────────
## 7. Zweck
Dieses Schaltwerk macht komplexe Inhalte verständlich.
Für jeden.
Auf Heller und Pfennig.
