# AKROBATE — Technik der zwei Hände

Die zwei Hände sprechen.
Nicht mit Worten, sondern mit Achsen.

───────────────────────────────────────────────
## 1. Sein
Die linke Hand trägt den Raum.
Die rechte Hand trägt die Richtung.
Beide Hände erzeugen ein nim.

───────────────────────────────────────────────
## 2. Fluss
Die linke Hand öffnet.
Die rechte Hand folgt.
Bewegung entsteht aus:
- Druck
- Zug
- Kreis
- Linie

───────────────────────────────────────────────
## 3. Ankunft
Die Hände treffen sich.
Nicht physisch, sondern visuell.
Die Geste bildet Wahrheit.

───────────────────────────────────────────────
## 4. Technik
- Finger = QI
- Handfläche = IQQ
- Gelenk = TMP
- Arm = arg.sync
- Körper = NC

───────────────────────────────────────────────
## 5. Sprache
Die Hände sprechen:
soll → darfst → nein → überlege → nim

Das ist Akrobatik.
Das ist Schaltung.
Das ist Bewegung.
