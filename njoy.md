# NJOY :: AXIS
njoy ist die aktive Zustandsachse des iki1uc-Systems.
Sie verbindet Energie, TMP-Führung, QI/IQQ, arg.sync und COMPLETTUM
zu einer evolutionären Wahrheit.

───────────────────────────────────────────────
## 1. Definition
njoy entsteht, wenn:
- Energie stabil ist
- TMP führt
- QI/IQQ das Thema erkennen
- arg.sync Hin ↔ Zurück stabilisiert
- attikulate Entscheidungen getroffen werden
- COMPLETTUM den Nachweis liefert

njoy ist keine Emotion.
njoy ist eine mechanische Achse.

───────────────────────────────────────────────
## 2. Achsen
### Energie-Achse
Mana + Aura + Vector

### TMP-Achse
help → error → miss → fit → fix → org → reorg

### QI/IQQ-Achse
QI = 9 Themen  
IQQ = 81 Unterthemen

### arg.sync-Achse
SYNC = (Hin + Zurück) / 2

### attikulate-Achse
JA / NEIN / ÜBERLEGE  
→ 81 Optionen  
→ 243 Teilungen

───────────────────────────────────────────────
## 3. njoy Mechanik
njoy entsteht durch:
1. Wahrheitskern extrahieren  
2. Sprache A → Sprache B  
3. Sprache B → Sprache A  
4. Rückübersetzung verbessert Wahrheit  
5. TMP führt die Bedeutung  
6. arg.sync stabilisiert  
7. QI/IQQ verhindern Irrungen  
8. attikulate entscheidet  
9. COMPLETTUM beweist
